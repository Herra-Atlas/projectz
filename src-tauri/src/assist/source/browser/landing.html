Assist

ProjectZ can answer a question you are looking at — a sum, a riddle, a fact — without you asking. It draws the answer beside the question, over the page. It only reads and draws: it never clicks, types or opens anything.

Set it up, once

  1. Download the extension

    This is the app handing over its own copy — no store, no account.

    Download projectz-assist.zip
  2. Load it in Chrome

    Unzip it, then open chrome://extensions, turn on Developer mode, choose Load unpacked, and pick the unzipped folder. Do this once per profile you want assist in.

    Pages you open from your own disk (file://) are left alone unless you ask for them twice: turn on Allow access to file URLs on that same details page, and the matching switch in the extension's settings.

  3. Reload this page

    The extension reads the pairing token from here itself, so there is nothing to copy. If the dot above turns green, it is done.

Pairing by hand, or a token that does not match

The token is what stops a web page from reaching the app's socket. Paste this into the extension's popup if it did not pair by itself, and replace it there if it drifts out of step.
