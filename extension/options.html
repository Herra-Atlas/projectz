Reading

What this browser reads on its own, and what it leaves alone. Whether an answer is worth giving, which model gives it and how often it may — all of that lives in ProjectZ, not here.

Read pages as you browse Off means nothing is read until you press Read in the popup.
Wait for the page to settle A page that is still loading or animating is not read until it stops.
Read local files Pages opened with file://. Off unless you ask for it here.

Only http, https and — if allowed above — local files are ever read. Browser pages, extension pages and devtools are not pages, and assist never asks for them.

Sites left alone

A site here is never read. The popup's switch adds the site you are on, which is usually faster.

What is sent

How much of a page may cross the wire on one look. These are this browser's own limits: they bound a request before ProjectZ ever sees it, which is what a page that changes constantly needs.

Blocks in one look The most text blocks sent at once. What is near the screen is kept first.
Longest block Characters of one block that may be sent. The rest is cut.

ProjectZ's own limits are read from the app.

A page whose text has not changed since the last look is not sent again — a request is what a look costs, and the same page has the same answer. Read this page now in the popup sends it regardless.

Answers

An answer is drawn in the page, beside the text it answers. Nothing here changes what is answered — only how it looks.

How an answer is drawn A card beside the text it answers.
Where a card goes It sits over the block it answers when there is room; this is where it goes when there is not.

Clicking an answer dismisses it, in both styles. Esc is not needed: an answer never takes focus.
